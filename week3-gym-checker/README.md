# 💪 AI GYM FORM CHECKER

> Pelatih olahraga berbasis AI yang menghitung repetisi dan mengecek form gerakan
> AI-powered gym trainer using MediaPipe Pose & OpenCV

## ✨ Fitur
- 🏋️ Push-up counter dengan form checker
- 🦵 Squat counter
- ⏱️ Plank timer
- 🔊 Suara hitung otomatis
- 📐 Analisis sudut sendi realtime
- ⚠️ Peringatan form salah

## 🎮 Cara Pakai
| Tombol | Fungsi |
|--------|--------|
| P | Mode Push-up |
| S | Mode Squat |
| L | Mode Plank |
| Q | Keluar |

## 🛠️ Teknologi
| Library | Fungsi |
|---------|--------|
| MediaPipe Pose | Deteksi 33 landmark tubuh |
| OpenCV | Kamera & tampilan |
| NumPy | Hitung sudut sendi |
| gTTS + pygame | Suara feedback |

cd week3-gym-checker
